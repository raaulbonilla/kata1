# Kata 1 - Ingeniería del Software 2

## Proyecto

El proyecto contiene una clase de dominio `Person` y una clase `Main` desde la que se crea y utiliza una instancia de dicha clase.

- Java / JDK: [26.0.2]
- IntelliJ IDEA
- Maven

Para ejecutar el proyecto, abrirlo en IntelliJ IDEA y ejecutar la clase `Main`.
